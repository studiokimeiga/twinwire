# Support

Twinwire is an independent open-source project maintained on a **best-effort basis**. There is no guaranteed response time, support level, or deadline for fixes or feature requests. A public issue or contribution does not create a maintenance or commercial support commitment.

- **Getting started and usage:** Check the [README](README.md), [guide](https://studiokimeiga.github.io/twinwire/), and [API documentation](docs/API.md).
- **Bug reports:** [Open an issue](https://github.com/studiokimeiga/twinwire/issues) with your Twinwire version, browser/OS or Node version, expected and actual behavior, and a minimal reproducible example. Include relevant transport mode and network conditions. Remove credentials and session or resume tokens from logs.
- **Feature requests:** Explain the game or integration requirement and why the existing API does not cover it. Requests may be declined to keep Twinwire focused and maintainable.
- **Code contributions:** See [CONTRIBUTING.md](CONTRIBUTING.md) for the checks and review expectations.
- **Security vulnerabilities:** Follow [SECURITY.md](SECURITY.md) and report privately, not in a public issue.

Commercial support, response-time guarantees, and custom integrations are not offered by default. Any such arrangement would need to be agreed separately.
